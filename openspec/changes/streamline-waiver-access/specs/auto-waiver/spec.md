# Streamline Waiver Specifications

## ADDED Requirements

### Requirement: Cross-Grid Highlighting
The system MUST link books to their associated fines visually. (Scenario: Select Book -> Select Fine).

### Requirement: Immediate Action Prompt
The system MUST offer immediate resolution for generated fines. (Scenario: Return -> Prompt -> Open Waiver).

### Requirement: Real-Time Status Synchronization
The system MUST ensure legacy views reflect the current return status immediately. (Scenario: Return in FormFine -> FormLoan updates "Status" to "Returned").
